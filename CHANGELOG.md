# История изменений FLOW BRIDGE (Changelog)

## [0.1.1] — 2026-10-10 (Release Candidate)

### Исправления безопасности и усиление ядра (V5 Final Enforcement)
* **Исправление ложного подтверждения перезагрузки (Blocker 1)**:
  - Устранена ошибка преждевременного подтверждения перезагрузки вкладки при наличии старого статуса `complete`.
  - Введена предварительная подписка на события жизненного цикла (`chrome.tabs.onUpdated`, `chrome.tabs.onRemoved`) до отправки запроса на перезагрузку.
  - Строго проверяется факт начала новой навигации (`status === 'loading'`) с последующим переходом в `complete`.
  - Статус `'complete'` без подтвержденной новой навигации отвергается (`NAVIGATION_UNCONFIRMED`), номер ревизии фиксируется без повышения.
  - Каждая активная вкладка отслеживается и проверяется строго независимо.
* **Привилегированная выгрузка скриптов (Blocker 2)**:
  - Стандартный путь управления (`syncRemoteControl`, Telegram-синхронизация, offline-кэш) безусловно переведен на привилегированную выгрузку динамических скриптов ядра Chromium (`chrome.scripting.unregisterContentScripts`).
  - Устранено использование недоверенной рефлексии страницы (`MAIN_GATE_APPLIED`) в качестве административного доказательства отключения.
  - Автоматическая перезагрузка открытых вкладок пользователей (`AUTO_RELOAD_ON_DISABLE_ENABLED`) оставлена отключенной по умолчанию в целях безопасности. При отключенной автоперезагрузке возвращается честный статус `ENFORCEMENT_UNCONFIRMED`.
* **Защита от атак по времени (Timing-Safe Auth)**:
  - Реализовано побитовое сравнение секретов авторизации постоянной длины без раннего выхода из цикла.
* **Изоляция хранилища и телеметрии**:
  - Строгая валидация входящих технических диагностических пакетов (ограничение 16 КБ, санитизация полей).
  - Защита от переопределения управляющего endpoint.

## [0.1.0] — 2026-10-06 (Initial Pilot Baseline)

* Базовая версия Chrome Extension Manifest V3.
* Локальный слой доступности для интерфейса Google Flow (`https://flow.google.com/`).
* Криптографическая проверка подписей управляющих манифестов Ed25519 (`extension-control-v3`).
* Монотонный антиоткат ревизий манифестов.
* Двухуровневая модель миграции (ISOLATED bootstrap + динамический MAIN world скрипт).
* Базовое всплывающее окно (popup) с диагностикой состояния.
