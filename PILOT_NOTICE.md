# Описание пилотной версии FLOW BRIDGE (v0.1.1)

## 1. Назначение и статус проекта

**FLOW BRIDGE** — это специализированный локальный слой доступности для веб-интерфейса Google Flow (`https://flow.google.com/`).

* **Статус**: Windows Beta (v0.1.1).
* **Модель распространения**: Распакованное расширение (Unpacked Extension) для Google Chrome в режиме разработчика.
* **Назначение**: Обеспечение доступности веб-интерфейса Google Flow для пользователей в неподдерживаемых регионах.

---

## 2. Архитектура и безопасность

1. **Криптографический Kill Switch**:
   - Расширение синхронизируется с сервером управления инфраструктуры через Ed25519-подписанные манифесты.
   - В случае выявления несовместимости инфраструктура может перевести расширение в режим `DISABLED` или `MAINTENANCE`.
   - Защита от отката: расширение монотонно повышает номер принятой ревизии и отклоняет любые устаревшие манифесты.
2. **Изоляция вкладок**:
   - Основная логика выполняется в изолированном контексте (`ISOLATED world`).
   - Динамический скрипт ядра (`MAIN world`) регистрируется только при активном статусе `ACTIVE`.
3. **Безопасность учетных записей**:
   - Расширение не подменяет авторизацию и не вмешивается в механизмы OAuth Google. Пользователь авторизуется в своем официальном аккаунте Google самостоятельно.

---

## 3. Техническое ограничение: Отключение открытых вкладок

> **ВАЖНОЕ ТЕХНИЧЕСКОЕ ОГРАНИЧЕНИЕ**:
> 
> По умолчанию в расширении отключена автоматическая перезагрузка открытых вкладок пользователей (`AUTO_RELOAD_ON_DISABLE_ENABLED = false`). Это сделано преднамеренно, чтобы не потерять несохраненные данные и текст запросов пользователя при аварийном сигнале.
> 
> **Как это работает на практике**:
> 1. При переходе расширения в состояние `DISABLED` регистрация скрипта в браузере немедленно аннулируется (`chrome.scripting.unregisterContentScripts`). Все **новые** вкладки и последующие переходы открываются без внедрения кода расширения.
> 2. Однако во **вкладках, которые уже были открыты и загружены ранее**, DOM-скрипт уже находится в памяти вкладки.
> 3. До тех пор, пока пользователь вручную не обновит вкладку (**F5**), статус полного применения отключения для этой вкладки считается незавершенным (`ENFORCEMENT_UNCONFIRMED`).
> 4. Для завершения отключения рекомендуется вручную перезагрузить открытые страницы `flow.google.com`.

---

## 4. Платформенная совместимость

* **Google Chrome на Windows**: Предварительно протестировано в тестовой среде разработчика на Windows (`BETA VERIFIED`). Полная совместимость со всеми сборками Chrome и разнообразными пользовательскими конфигурациями Windows не заявляется и требует расширенного тестирования.
* **Google Chrome на macOS**: Архитектурно совместимо, статус: `NOT VERIFIED` (ожидает аппаратной проверки владельцем на физическом устройстве Mac).
* **Автоматические обновления**: Для распакованных расширений (unpacked) автообновление в браузере не поддерживается. Обновления производятся вручную заменой файлов в директории расширения.
