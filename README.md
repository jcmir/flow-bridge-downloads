## Краткие технические характеристики (v0.1.1)

* **Архитектура**: Chrome Extension Manifest V3 (Google Chrome 111+).
* **Модель безопасности**: Криптографически подписанное удаленное управление (Ed25519) с антиоткатом ревизий (monotonic anti-rollback).
* **Привилегированная выгрузка**: Физическое удаление динамического скрипта из ядра Chromium (`chrome.scripting.unregisterContentScripts`) при поступлении команды `DISABLED`.
* **Телеметрия**: Минимальная техническая телеметрия флота (статусы синхронизации, сетевые ошибки, `installation_id`). Промпты, чаты и содержимое страниц **не передаются**.
* **Статус платформ**:
  - **Windows (Chrome)**: `BETA VERIFIED` — подтверждено сквозным E2E-тестированием владельца.
  - **macOS (Chrome)**: `NOT VERIFIED` — архитектурно совместимо, ожидает аппаратной проверки владельцем на macOS.
* **Модель обновлений**: Так как расширение устанавливается в распакованном виде (Developer Mode), автоматическое обновление файлов через Chrome Web Store **не производится**. Обновление выполняется заменой файлов в локальной папке.
