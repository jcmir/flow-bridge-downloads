# FLOW BRIDGE — Google Flow в Chrome

**FLOW BRIDGE** — независимое расширение для Google Chrome, которое помогает пользоваться веб-интерфейсом Google Flow в регионах, где доступ к сервису ограничен.

Расширение устанавливается в обычный Google Chrome. Не требует установки отдельного браузера.

**Версия:** 0.1.1 Beta  
**Windows:** протестировано  
**macOS:** ожидает проверки

### Как начать

1. Скачайте архив FLOW BRIDGE.
2. Распакуйте его в постоянную папку.
3. Откройте `chrome://extensions` и включите режим разработчика.
4. Выберите «Загрузить распакованное расширение».
5. Откройте Google Flow и проверьте статус FLOW BRIDGE.

Подробные инструкции и скриншоты доступны в [руководстве по установке](INSTALL.md).

---

### Что важно знать

FLOW BRIDGE использует подписанное дистанционное управление, которое позволяет отключать работу расширения при обнаружении несовместимости. При отключении уже открытые вкладки может потребоваться обновить вручную.

Расширение локально обрабатывает отдельные сетевые ответы Google Flow. Для диагностики работы отправляется ограниченная техническая телеметрия. Подробнее — в [политике конфиденциальности](PRIVACY.md).

Расширение распространяется в бета-версии. Работа Google Flow может зависеть от изменений сервиса, аккаунта и других условий доступа.

FLOW BRIDGE не является официальным продуктом Google и не аффилирован с Google.
