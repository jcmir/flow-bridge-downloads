# Политика безопасности FLOW BRIDGE (Security Policy)

## 1. Сообщение об уязвимостях (Reporting a Vulnerability)

Безопасность пользователей и целостность инфраструктуры являются наивысшим приоритетом. Если вы обнаружили потенциальную уязвимость или ошибку в безопасности расширения FLOW BRIDGE:

* **Контакт для связи**: Telegram: [@ITHRONIC](https://t.me/ITHRONIC) или создание приватного Security Advisory в GitHub.
* **Сроки реагирования**: Первичное подтверждение получения отчета осуществляется в течение 24 часов.
* **Принцип ответственного раскрытия (Coordinated Disclosure)**: Мы просим не публиковать детали уязвимости до выпуска официального обновления безопасности.

## 2. Модель доверия и криптографическая архитектура

FLOW BRIDGE v0.1.1 построен на базе строгой криптографической модели Manifest V3:

1. **Криптографическая подпись Ed25519**:
   - Любое удаленное управление состоянием расширения (`ACTIVE`, `DISABLED`, `MAINTENANCE`) осуществляется только через манифесты, подписанные закрытым доверенным ключом Ed25519 Authority.
   - Публичный ключ вшит в исходный код расширения. Подделка или подмена управляющих команд в сети исключена математически.
2. **Антиоткат ревизий (Monotonic Anti-Rollback)**:
   - Расширение сохраняет монотонно возрастающий счетчик ревизий (`enforced_revision`).
   - Манифесты с меньшим или равным номером ревизии, а также манифесты с истекшим сроком действия (`expires_at`) немедленно отклоняются.
3. **Привилегированная выгрузка скриптов**:
   - При получении команды `DISABLED` расширение выполняет физическую отмену регистрации скрипта на уровне движка Chromium (`chrome.scripting.unregisterContentScripts`).
   - Расширение не полагается на недоверенную рефлексию страницы.
4. **Защита от атак по времени (Timing Attack Resistance)**:
   - Проверка авторизационных заголовков и токенов выполняется с использованием алгоритмов постоянного времени без раннего выхода из цикла.
5. **Политика защиты контента (CSP)**:
   - Полный запрет выполнения небезопасного кода (`unsafe-eval`), загрузка внешних скриптов с произвольных хостов запрещена на уровне манифеста Chrome.

## 3. Границы ответственности и ограничения

* **Открытые вкладки при kill switch**:
  - По умолчанию автоматическая перезагрузка открытых вкладок пользователя отключена (`AUTO_RELOAD_ON_DISABLE_ENABLED = false`), чтобы предотвратить потерю пользовательских черновиков.
  - При поступлении команды `DISABLED` новые вкладки открываются чистыми, однако для гарантированной выгрузки кода из ранее открытых вкладок требуется ручное обновление страницы (**F5**).
* **Учетные записи Google**:
  - FLOW BRIDGE не перехватывает пароли, токены OAuth, куки сессий или учетные записи Google. Пользователь авторизуется в Google стандартным образом.
* **Ограничение платформы**:
  - Версия v0.1.1 проверена и верифицирована на платформе Google Chrome (Windows). Для macOS сборка архитектурно совместима, но ожидает физического подтверждения на оборудовании.
