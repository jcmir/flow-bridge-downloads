# Политика безопасности FLOW BRIDGE (Security Policy)

## 1. Сообщение об уязвимостях (Reporting a Vulnerability)

Безопасность пользователей и целостность инфраструктуры являются важным приоритетом проекта. Если вы обнаружили потенциальную уязвимость или ошибку в безопасности расширения FLOW BRIDGE:

* **Контакт для связи**: Telegram: [@ITHRONIC](https://t.me/ITHRONIC) или создание приватного Security Advisory в GitHub.
* **Сроки реагирования**: Первичное подтверждение получения отчета осуществляется в течение 24 часов.
* **Принцип ответственного раскрытия (Coordinated Disclosure)**: Мы просим не публиковать детали уязвимости до выпуска официального обновления безопасности.

## 2. Модель доверия и архитектура безопасности

FLOW BRIDGE v0.1.1 построен на базе криптографической модели Manifest V3:

1. **Криптографическая подпись Ed25519**:
   - Удаленное управление состоянием расширения (`ACTIVE`, `DISABLED`, `MAINTENANCE`) осуществляется через манифесты, подписанные закрытым доверенным ключом Ed25519 Authority.
   - Публичный ключ встроен в исходный код расширения. Проверка цифровой подписи Ed25519 обеспечивает защиту от несанкционированной подделки или подмены управляющих манифестов при передаче по сети.
2. **Антиоткат ревизий (Monotonic Anti-Rollback)**:
   - Расширение сохраняет монотонно возрастающий счетчик ревизий (`enforced_revision`).
   - Манифесты с меньшим или равным номером ревизии, а также манифесты с истекшим сроком действия (`expires_at`) отклоняются.
3. **Привилегированная выгрузка скриптов**:
   - При получении команды `DISABLED` расширение выполняет выгрузку скрипта на уровне движка Chromium (`chrome.scripting.unregisterContentScripts`).
   - Расширение не полагается на недоверенную рефлексию страницы.
4. **Защита от атак по времени (Timing Attack Resistance)**:
   - Проверка авторизационных заголовков и токенов выполняется с использованием алгоритмов постоянного времени без раннего выхода из цикла.
5. **Политика защиты контента (CSP)**:
   - Запрещено выполнение динамического кода (`unsafe-eval`), загрузка внешних скриптов с произвольных хостов ограничена правилами CSP манифеста Chrome.

## 3. Границы ответственности и ограничения

* **Открытые вкладки при kill switch**:
   - По умолчанию автоматическая перезагрузка открытых вкладок пользователя отключена (`AUTO_RELOAD_ON_DISABLE_ENABLED = false`), чтобы предотвратить потерю пользовательских черновиков.
   - При поступлении команды `DISABLED` новые вкладки открываются без вмешательства расширения. Однако для полной выгрузки кода из ранее открытых вкладок требуется ручное обновление страницы (клавиша **F5** в Windows или **Cmd+R** в macOS).
* **Учетные записи Google**:
   - FLOW BRIDGE не перехватывает пароли, токены OAuth, куки сессий или учетные записи Google. Пользователь авторизуется в Google стандартным образом.
* **Платформы и статус**:
   - **Поддерживаемые платформы: Windows и macOS.**
   - **Статус: Beta.**
